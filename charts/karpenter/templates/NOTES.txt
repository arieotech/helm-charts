Prerequisites (this chart ships NO CRDs — that is the ArgoCD-drift fix, upstream #6847):
  1. Install the CRDs first:
       helm install karpenter-crds arieotech/karpenter-crds -n {{ .Release.Namespace }}
  2. Give the controller an AWS identity via IRSA or EKS Pod Identity by annotating its
     ServiceAccount ({{ include "karpenter.serviceAccountName" . }}) with the IAM role ARN:
       serviceAccount.annotations."eks\.amazonaws\.com/role-arn"=arn:aws:iam::<acct>:role/<role>

Check rollout:
  kubectl rollout status deploy/{{ include "karpenter.fullname" . }} -n {{ .Release.Namespace }}

Then create a NodePool + EC2NodeClass to start provisioning nodes. See:
  https://karpenter.sh/docs/getting-started/

Run the bundled smoke test:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
